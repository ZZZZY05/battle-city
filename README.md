# 坦克大战 Battle City

经典红白机（FC）风格的 HTML5 坦克大战游戏，纯原生 JavaScript 实现，零依赖，打开即玩。

## 在线试玩

开启 GitHub Pages 后访问：**https://zzzzy05.github.io/battle-city/**

本地试玩：直接用浏览器打开 `index.html` 即可，无需任何服务器或构建工具。

## 操作方式

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动坦克 |
| 空格 | 射击（同屏最多 2 发） |
| Enter | 开始 / 确认 |
| P | 暂停 / 继续 |

## 玩法

- 驾驶黄色坦克，消灭每关 **20 辆** 敌方坦克即可过关，共 **3 关**
- **保护基地**：底部中央的老鹰被击中即游戏结束
- 地形：
  - 🧱 砖墙 —— 可被子弹逐格打碎
  - ⬜ 钢墙 —— 坚不可摧
  - 🌊 水域 —— 坦克无法通过，子弹可以飞越
  - 🌿 草丛 —— 提供隐蔽
- 敌方坦克 3 种类型：
  - 灰色 **普通型**（100 分）
  - 蓝色 **快速型**（200 分）
  - 红色 **火力型**（300 分，2 点血量，子弹更快）
- 玩家 3 条命，过关奖励 500 分，敌人越往后越快越强

## 技术说明

- 纯 HTML5 Canvas + 原生 JavaScript，无任何外部依赖
- 26×26 小格战场（每格 20px），砖墙按小格独立摧毁
- 音效使用 WebAudio 振荡器实时合成，无音频文件
- 敌人 AI：随机巡逻 + 向基地方向推进
